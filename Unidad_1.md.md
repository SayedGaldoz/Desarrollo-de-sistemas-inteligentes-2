1. Basados en reglas y conocmientos: El conocimiento se codifica de forma explicita como hechos y reglas y un motor de interferencia razona con ellos para llegar a conclusiones

2.  Machine Learning: El Sistema induce su funcion de decision a partir de datos de ejemplo, en vez de que un humano la escriba regla por regla

3. Redes Neuronales y Aprendizaje: Modelo compuesto por capas de unidades interconectadas que aprenden representaciones cada vez mas abstractas de los datos. Algunos ejemplos pueden ser tensorflow y pytorch

4. Sistemas Difusos (Fuzzy): Sistema que maneja datos de pertenencia entre 0 y 1 en vez de una logica estrictamente verdadeor/falso

5. Sistemas Multiagente: Sistema Compuesto por varios agentes autonomos que interactuan entre si cooperando, o compitiendo, dentro de un mismo entorno

6. Razonamiento basado en casos: Resuelve un problema nuevo recuperando el caso mas parecido ya resuelto y adapatando su solucion
