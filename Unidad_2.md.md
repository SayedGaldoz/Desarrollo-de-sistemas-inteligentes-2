**Actividad 2.3**

Pandas: Una Biblioteca usada en python la cual transforma y limpia datos


MatPlotLib: Una Biblioteca de python usada  para crear graficas y estadisticas


Scikit-learn: Biblioteca especializada en aprendizaje automatico 


Google Colab: entorno gratuito basado en la nube que permite escribir y ejecutar código Python directamente desde el navegador web 


Arbol de decision: algoritmo de aprendizaje automático supervisado que predice resultados dividiendo los datos en partes


Matriz de confusion: Tabla que evalúa el rendimiento de un modelo 


SobreAjuste: ocurre cuando un modelo de aprendizaje automático aprende los datos de entrenamiento demasiado bien


Falso Positivo: Ocurre cuando un modelo precide de manera positiva una muestra que en realidad es positiva


Falso Negativo: Ocurre cuando un modelo precide de manera positiva una muestra que en realidad es negativa
